## 它解决什么问题

这个 Skill 负责回答：**我在哪里、这里有什么、下一步能去哪、怎么回去。**

## 核心理念

> 导航首先是信息结构和定向系统，不是一个 Header 组件。

## 它主要负责

- Information Architecture。
- Global / Local / Contextual Navigation。
- Current Location、Back、Breadcrumb。
- 信息层级与标签。
- Search 与 Browse 的分工。
- Deep Link 和返回后的上下文保持。

## 它不负责

- Link 怎么表现可点击：看 `interaction-affordance`。
- 导航在手机上怎么折叠：看 `adaptive-layout`。
- 导航视觉材质：看 `apple-design`。
