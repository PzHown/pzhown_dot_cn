# 研究与规范来源

本 Skill 将认知心理学和现代设计规范转译为通用 UI 规则，不把研究结论伪装成精确公式。

主要参考：

- Apple Human Interface Guidelines · Design principles: https://developer.apple.com/design/human-interface-guidelines/design-principles
- Cognitive load and interface complexity / interruption recovery: https://www.sciencedirect.com/science/article/pii/S0169814125000678
- Cognitive Load in Software Usability systematic review: https://pubmed.ncbi.nlm.nih.gov/41849193/
- W3C Making Content Usable for People with Cognitive and Learning Disabilities: https://www.w3.org/TR/coga-usable/

采用的稳定结论：减少不必要复杂度、优先识别而非回忆、保持一致心智模型、支持任务恢复和渐进披露。
